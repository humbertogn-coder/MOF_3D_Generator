# Manuscript v4 and SI v2 — what changed relative to v3 / SI v1.1

Prepared 2026-10-16 from the repository at commit (see bundle). Every number in the text, tables and
figures is produced by a script in the repository; nothing is typed by hand.

## Why the text was rewritten rather than edited
The DFT validation set of v3 (18 structures, 15 "converged") was built on structures with overlapping
atoms and mislabelled chemistry (see the pre-submission review). The whole campaign was redone on a
chemically audited catalogue with a new protocol (CHGNet pre-relaxation, PBE-D3(BJ) full relaxation,
broken-symmetry spin states, explicit acceptance rules). Results, figures, tables and conclusions are
therefore new; the introduction and methods were rewritten around them.

- Abstract: 250 words (CMS limit 250), 7 keywords. Highlights (5 x <= 85 characters) in a separate file.
- Graphical abstract (1535 x 614 px, matplotlib) in results/figures/graphical_abstract.png/.pdf.

## Main claims, v3 -> v4
| v3 | v4 |
|---|---|
| 200-structure catalogue, 6 nets, 7 metals, Zr fcu and reo | 131 frameworks after QC (168 built), 5 nets, 16 audited M(II) carboxylate nodes, 8 linkers |
| "100 % classification accuracy", MAE 0.60 -> 0.45 -> 0.25 eV, "58 % reduction" | Prospective MAE 0.44 / 0.43 / 0.43 eV per iteration; open-shell 0.23 eV, Zn4O 0.96 eV; retraining does not fix the Zn4O bias |
| "bcu/reo with open-shell metals give gaps < 0.2 eV" | 13 open-shell labels all < 1 eV (8 < 0.5 eV); Fe nearly gapless, Co 0.33-0.67 eV, Cu 0.34-0.90 eV (AFM) |
| "substituent has no systematic effect" | Substituents move the gap by up to 1 eV in Zn4O (linker band edges) and <= 0.2 eV in Co/Fe (metal d band edges); Cu NH2 is the exception |
| PDOS at E_F (+/-0.1 eV), "ligand p 59 % vs metal d 36 %", "flat bands" | Band-edge projections within 0.25 eV of VBM/CBM in four site groups; DOS figures for all 18 labels; no "flat band" inference |
| xTB "fails for MOFs" (finite clusters) | Periodic xTB reproduces closed-shell labels within 0.14-0.23 eV; the cluster artefact is reported; open-shell failure as in Jose & Walsh 2026 |
| no failures reported | 9 non-accepted frameworks reported with cause and cost (Table S13); 24,600 core-hours in total |
| no retrospective test | Retrospective AL benchmark on QMOF (Fig. 8, Table S19) |
